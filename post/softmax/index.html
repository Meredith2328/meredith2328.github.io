softmax形式推导

我们讨论的起点是原始的softmax形式：

pj=ezj∑kezk.p_j = \frac{e^{z_j}}{\sum_k e^{z_k}}. pj​=∑k​ezk​ezj​​.

为保证数值稳定，令

m:=max⁡kzk,m := \max_k z_k, m:=kmax​zk​,

则 softmax 可等价改写为数值稳定的softmax形式：

pj=ezj−m∑kezk−m.p_j = \frac{e^{z_j - m}}{\sum_k e^{z_k - m}}. pj​=∑k​ezk​−mezj​−m​.

其实就是给分子分母的 zzz 先减去 mmm ，然后再使用exp函数，相当于给 pjp_jpj​ 计算式的分子分母除以 eme^mem ，计算得到的 pjp_jpj​ 值不变。
这样的好处是，如果某个 zzz 值非常大，本来exp一下就溢出了（脑补一下指数函数的图像，比较大时能够狠狠地增大数值），可是我们先减了下来再exp，原理上计算得到的 pjp_jpj​ 值不会发生变化。

对其取对数，得到 log-softmax：

log⁡pj=zj−m−log⁡∑kezk−m.\log p_j = z_j - m - \log \sum_k e^{z_k - m}. logpj​=zj​−m−logk∑​ezk​−m.

其中

LSE⁡(z):=m+log⁡∑kezk−m\operatorname{LSE}(z) := m + \log \sum_k e^{z_k - m} LSE(z):=m+logk∑​ezk​−m

称为 log-sum-exp，因此也可写为

log⁡pj=zj−LSE⁡(z).\log p_j = z_j - \operatorname{LSE}(z). logpj​=zj​−LSE(z).

接下来，我们考虑如何修改为在线softmax，以支持FlashAttention的分块计算？

核心是：在有了新块中得分的最大值 minewm_i^{new}minew​ 之后，我们需要把已计算的最大值 mi(j)m_i^{(j)}mi(j)​ 更新为

mi(j+1)←max⁡{mi(j),minew}m_i^{(j+1)} \leftarrow \max \{m_i^{(j)}, m_i^{new}\} mi(j+1)​←max{mi(j)​,minew​}

更新后的 mmm 可能会影响新的块和已计算的部分的softmax值。因此，需要给已计算过的部分乘以修正系数，并且应该用更新后的 mmm 计算新的块。
总之，关键问题是，要用正确的最大值 mmm 计算softmax。

详细来看，是以下这样的：
对第 iii 个 query，设第 jjj 轮已经处理完前 jjj 个列块。定义当前累计最大值为

mi(j):=max⁡k≤jBcsik,m_i^{(j)} := \max_{k \le jB_c} s_{ik}, mi(j)​:=k≤jBc​max​sik​,

线性归一化项（其实就是分母那一堆e的求和的高级叫法）为

ℓi(j):=∑k≤jBce sik−mi(j),\ell_i^{(j)} := \sum_{k \le jB_c} e^{\,s_{ik} - m_i^{(j)}}, ℓi(j)​:=k≤jBc​∑​esik​−mi(j)​,

未归一化输出累计量（其实就是没归一化的分子乘积的高级叫法）为

o~i(j):=∑k≤jBce sik−mi(j)vk.\tilde{o}_i^{(j)} := \sum_{k \le jB_c} e^{\,s_{ik} - m_i^{(j)}} v_k. o~i(j)​:=k≤jBc​∑​esik​−mi(j)​vk​.

因此，当前输出可写为

oi(j)=o~i(j)ℓi(j).o_i^{(j)} = \frac{\tilde{o}_i^{(j)}}{\ell_i^{(j)}}. oi(j)​=ℓi(j)​o~i(j)​​.

若第 j+1j+1j+1 个新块对应的 score 集合为 k∈blockj+1k \in \text{block}_{j+1}k∈blockj+1​，记该块内最大值为

minew:=max⁡k∈blockj+1sik.m_i^{\mathrm{new}} := \max_{k \in \text{block}_{j+1}} s_{ik}. minew​:=k∈blockj+1​max​sik​.

则合并后的最大值更新为

mi(j+1):=max⁡{mi(j), minew}.m_i^{(j+1)} := \max\{m_i^{(j)},\, m_i^{\mathrm{new}}\}. mi(j+1)​:=max{mi(j)​,minew​}.

由于归一化基准从 mi(j)m_i^{(j)}mi(j)​ 变成了 mi(j+1)m_i^{(j+1)}mi(j+1)​，旧块对应的指数项都要乘上修正系数

e mi(j)−mi(j+1).e^{\,m_i^{(j)} - m_i^{(j+1)}}. emi(j)​−mi(j+1)​.

因此，未归一化输出的递推公式为

o~i(j+1)=e mi(j)−mi(j+1)o~i(j)+∑k∈blockj+1e sik−mi(j+1)vk.\tilde{o}_i^{(j+1)} = e^{\,m_i^{(j)} - m_i^{(j+1)}} \tilde{o}_i^{(j)} + \sum_{k \in \text{block}_{j+1}} e^{\,s_{ik} - m_i^{(j+1)}} v_k. o~i(j+1)​=emi(j)​−mi(j+1)​o~i(j)​+k∈blockj+1​∑​esik​−mi(j+1)​vk​.

同理，线性归一化项满足

ℓi(j+1)=e mi(j)−mi(j+1)ℓi(j)+∑k∈blockj+1e sik−mi(j+1).\ell_i^{(j+1)} = e^{\,m_i^{(j)} - m_i^{(j+1)}} \ell_i^{(j)} + \sum_{k \in \text{block}_{j+1}} e^{\,s_{ik} - m_i^{(j+1)}}. ℓi(j+1)​=emi(j)​−mi(j+1)​ℓi(j)​+k∈blockj+1​∑​esik​−mi(j+1)​.

最终输出为

oi(j+1)=o~i(j+1)ℓi(j+1).o_i^{(j+1)} = \frac{\tilde{o}_i^{(j+1)}}{\ell_i^{(j+1)}}. oi(j+1)​=ℓi(j+1)​o~i(j+1)​​.

当然，若记块内的未归一化输出与归一化项分别为

o~inew:=∑k∈blockj+1e sik−mi(j+1)vk,\tilde{o}_i^{\mathrm{new}} := \sum_{k \in \text{block}_{j+1}} e^{\,s_{ik} - m_i^{(j+1)}} v_k, o~inew​:=k∈blockj+1​∑​esik​−mi(j+1)​vk​,

ℓinew:=∑k∈blockj+1e sik−mi(j+1),\ell_i^{\mathrm{new}} := \sum_{k \in \text{block}_{j+1}} e^{\,s_{ik} - m_i^{(j+1)}}, ℓinew​:=k∈blockj+1​∑​esik​−mi(j+1)​,

则也可简写为

o~i(j+1)=e mi(j)−mi(j+1)o~i(j)+o~inew,\tilde{o}_i^{(j+1)} = e^{\,m_i^{(j)} - m_i^{(j+1)}} \tilde{o}_i^{(j)} + \tilde{o}_i^{\mathrm{new}}, o~i(j+1)​=emi(j)​−mi(j+1)​o~i(j)​+o~inew​,

ℓi(j+1)=e mi(j)−mi(j+1)ℓi(j)+ℓinew.\ell_i^{(j+1)} = e^{\,m_i^{(j)} - m_i^{(j+1)}} \ell_i^{(j)} + \ell_i^{\mathrm{new}}. ℓi(j+1)​=emi(j)​−mi(j+1)​ℓi(j)​+ℓinew​.

总之，再来一遍结论。在线 softmax 的关键就在于：
每次加入新块时，都要先用新的全局最大值

mi(j+1)m_i^{(j+1)} mi(j+1)​

重新对旧块和新块做统一归一化，再更新 ℓi\ell_iℓi​ 与 o~i\tilde{o}_io~i​，最后得到输出 oio_ioi​。

softmax实际代码实现

接下来联系到实际的代码实现，特别是softmax和log-sum-exp的PyTorch实现及其与交叉熵损失和FlashAttention的关系。

标准的数值稳定softmax应该为：
总之就是首先需要计算一个最大值，然后计算减去最大值后的softmax。

import torch

def softmax_stable(logits, dim=-1):
    """
    logits: [..., n]
    return: [..., n] 概率分布
    """
    # 减去最大值防止溢出
    max_val = torch.max(logits, dim=dim, keepdim=True)[0]
    exp_logits = torch.exp(logits - max_val)
    sum_exp = torch.sum(exp_logits, dim=dim, keepdim=True)
    return exp_logits / sum_exp

# PyTorch 内置版本（推荐，数值更稳定）
# attn_weights = torch.softmax(scores, dim=-1)

而交叉熵损失则为：

def cross_entropy_loss(logits, labels):
    """
    logits: [batch_size, num_classes] 原始输出（未经过 softmax）
    labels: [batch_size] 真实类别索引 (0 ~ num_classes-1)
    """
    # 先算 log_softmax（数值稳定）
    max_val = torch.max(logits, dim=1, keepdim=True)[0]
    exp_logits = torch.exp(logits - max_val)
    sum_exp = torch.sum(exp_logits, dim=1, keepdim=True)
    log_probs = logits - max_val - torch.log(sum_exp)  # log(softmax)
    
    # 取出正确类别的 log 概率
    batch_size = logits.shape[0]
    correct_log_probs = log_probs[range(batch_size), labels]
    
    return -correct_log_probs.mean()

# PyTorch 内置版本（推荐，数值更稳定）
# loss_fn = torch.nn.CrossEntropyLoss()  # 内部自动做 log_softmax + NLLLoss

在线Softmax的核心实现则为：
其中 BrB_rBr​ 是行row的块大小（即 QQQ 的块大小，因为是 QKTQK^TQKT ），
BcB_cBc​ 是列column的块大小。

def flash_attention_online_softmax(Q, K, V, B_r, B_c):
    """
    B_r: Q 的块大小，B_c: K/V 的块大小
    Q, K, V: [n, d] 假设 batch=1, heads=1 简化
    """
    n, d = Q.shape
    O = torch.zeros_like(Q)  # 输出累加器
    l = torch.zeros(n, 1)    # 指数和统计量
    m = torch.full((n, 1), -float('inf'))  # 最大值统计量
    
    # 外层循环：遍历 KV 块
    for j in range(0, n, B_c):
        Kj = K[j:j+B_c]  # [B_c, d]
        Vj = V[j:j+B_c]  # [B_c, d]
        
        # 内层循环：遍历 Q 块
        for i in range(0, n, B_r):
            Qi = Q[i:i+B_r]  # [B_r, d]
            Oi = O[i:i+B_r]  # [B_r, d]
            mi = m[i:i+B_r]  # [B_r, 1]
            li = l[i:i+B_r]  # [B_r, 1]
            
            # 计算当前块的得分矩阵 [B_r, B_c]
            Sij = torch.matmul(Qi, Kj.T) / (d ** 0.5)
            
            # 当前块的最大值（每行）
            mij_new = torch.max(Sij, dim=1, keepdim=True)[0]  # [B_r, 1]
            
            # 当前块的指数和（以块内最大值归一化）
            Pij = torch.exp(Sij - mij_new)  # [B_r, B_c]
            lij_new = torch.sum(Pij, dim=1, keepdim=True)  # [B_r, 1]
            
            # 当前块的加权输出（块内）
            Oij_new = torch.matmul(Pij, Vj)  # [B_r, d]
            
            # ========== 在线 softmax 合并 ==========
            # 更新全局最大值
            m_new = torch.maximum(mi, mij_new)  # [B_r, 1]
            
            # 缩放旧统计量
            scale_old = torch.exp(mi - m_new)   # [B_r, 1]
            scale_new = torch.exp(mij_new - m_new)  # [B_r, 1]
            
            # 更新指数和
            l_new = scale_old * li + scale_new * lij_new  # [B_r, 1]
            
            # 更新输出（关键：旧的输出需要按比例缩放）
            O_new = (scale_old * Oi * li + scale_new * Oij_new) / l_new
            
            # 写回
            O[i:i+B_r] = O_new
            m[i:i+B_r] = m_new
            l[i:i+B_r] = l_new
    
    return O
