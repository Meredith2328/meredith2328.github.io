令牌：未设置

    
    
发布需要仓库主人在这台设备上设置 GitHub 令牌。没有令牌也能照常写作、预览和导出；页面不会替任何人申请或获得仓库权限。

    
    
    
    
  
    

    


    
  
    GITHUB 令牌仅存本机
    
  
    
    
    
      
    未设置
    
      
    没有令牌时「发布」保持锁定
    
    
    
    
    
      
      
    
    
    
    
    
      
      
    
    
    
    
    
    令牌只保存在这台设备的浏览器里，只随请求直接发往 api.github.com。这个页面没有后端，不会上传令牌，也不会把它写进稿件或导出文件。不要在别人的设备或共用浏览器上保存。
    

    
    如何创建（只需一次）
    
    
    
      
      
        
    1. 新建 fine-grained token
          
      GitHub → Settings → Developer settings → Fine-grained tokens → Generate new token，或直接打开 创建页面。
      2. 
        
    2. 只选一个仓库
          
      Resource owner 选 Meredith2328；Repository access 选 Only select repositories → Meredith2328/pilog。
      3. 
        
    3. 只开两项权限
          
      Contents: Read and write 和 Pull requests: Read and write（Metadata: Read 会自动带上）。其余全部保持 No access。
      4. 
        
    4. 设置到期时间，复制粘贴到上面
          
      丢了手机或怀疑泄露时，到 GitHub 令牌页 Revoke 即可立即失效。详见 GitHub 文档。
      5. 
      
    
    
    
    
    发布只会在 Meredith2328/pilog 新建 write/… 分支并开 PR 到 pilog，从不直接推送 pilog，也不会自动合并。

    在 Android 上使用
    
  
    
    
      
      
    1. 在线打开
        
      博客导航栏的「写作」，或直接访问 https://meredith2328.github.io/write/。页面是纯静态的，写作、预览、草稿照样离线可用。
      2. 
      
    2. 本地打开（离线可用）
        
      把仓库里的 tools/write.html 存到手机，在「文件」里点开并选择 Chrome。写作、预览、草稿都不需要网络。
      3. 
      
    3. 或者走电脑的本地服务
        
      电脑与手机连同一个 Wi‑Fi，在仓库目录运行：
      
        
      python pilog.py serve --host 0.0.0.0
      
        
      手机访问 http://电脑IP:8000/write。电脑本机则直接开 http://127.0.0.1:8000/write。
      4. 
      
    4. 添加到主屏幕
        
      Chrome 菜单 → 添加到主屏幕，之后像 App 一样一点就开。请固定用同一种方式打开：本地文件和网址的草稿存储互不相通。
      5. 
      
    5. 交稿
        
      「导出」下载 .md，放到 blogs/posts/分类/ 后提交到 pilog 分支即可自动部署。
      6. 
      
    6. 或者直接开 PR（仅仓库主人）
        
      在「稿件 → GitHub 令牌」粘贴只授权 Meredith2328/pilog 的 fine-grained token，之后「导出 → 发布（开 PR）」会新建 write/日期-文件名 分支并开 PR 到 pilog，在 GitHub 上审阅后手动合并。
      7. 
      
    7. 修改已发布的文章
        
      文章页点「✎ 编辑」，或在「稿件 → 编辑线上文章」的下拉菜单中依次选择目录和文章，从 pilog 分支载入原文；改完发布会开一个「更新文章」PR，需要手动合并。
      8. 
    
    
    
    预览尽量贴近博客渲染，但图片只显示占位（手机上读不到仓库里的 assets/），公式显示为源码。
